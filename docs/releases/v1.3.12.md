# Planly Plugin v1.3.12

日期：2026-10-28。发布标签：`v1.3.12`。用户在本地验证后授权提交、打标签并推送，本次使用新标签发布，不覆盖既有标签。

## 变更

- Plugin 根版本、清单、内置 Skill 与 Gateway 源 Skill 的版本统一为 `1.3.12`。
- Plugin 和两份 Skill 的展示名称及默认提示统一为「Planly 规划助理」，去掉“智能”二字；技术标识 `planly` 和 `planly-solver` 不变。
- 两个仓库的公开 Skill 共 16 个文件逐字节一致，仅更新版本声明和 UI 元数据，求解指导正文及其余参考与脚本不变。
- 沿用 `v1.3.11` 的正式品牌资源、字体许可、端点、MCP / OAuth 配置及市场身份，不升级 Gateway 应用自身的构建版本。

## 验证与边界

验证覆盖版本和名称契约、两份 Skill 的结构与逐字节一致性、接入脚本、MCP 配置生成及 Gateway 内嵌 Skill 的 JVM 打包。执行结果见 [验收清单](../acceptance.md)，Gateway 的实际来源提交见 [同步记录](../gateway-skill-sync.md)。

本次仅提交和发布源码，不部署服务、不更新用户安装或 OAuth 登录页品牌。此前本地重打的 `v1.3.11` 与远端同名标签指向不同提交，本次不处理该历史差异，也不覆盖远端发布。真实客户端名称、安装与缓存仍待独立验收，源码发布不代表服务或客户端已更新。
