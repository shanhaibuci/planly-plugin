# Planly Plugin v1.3.13

日期：2026-11-04。状态：用户随后授权推送，源码及 annotated 标签 `v1.3.13` 已发布到 GitHub。标签保留原已验证提交 `b43c9db7e4d7e6ce6aee6dae156748100a752b2d`；发布状态文档由后续主线提交更新。

本版将插件与独立 Skill 的公开 MCP 入口同步到 Planly 新域名。根版本、Plugin 清单和内置 Skill 均为 `1.3.13`；展示名称仍为「Planly 规划助理」，技术标识、品牌资产和求解指导不变。

- `config/system-endpoint.json` 的唯一 origin 更新为 `https://app.planly.cn`，生成的插件 `.mcp.json` 使用 `https://app.planly.cn/mcp`。
- Gateway Protected Resource Metadata 提供新 resource `https://app.planly.cn/mcp` 和 Issuer `https://auth.planly.cn/oidc`，不在插件中另建发现或资源配置。
- 既有公开 Client ID、回环 callback、`gateway:mcp` 与 `offline_access` 的内容和顺序保持不变；不新增秘密、身份资料或管理权限。
- 内置 Skill 的 16 个公开文件与 Gateway 提交 `5cc22a2a9f31041951bc5042f00f5e6ba4603e63` 中的 `skills/planly-solver/` 逐字节一致，文件树 SHA-256 为 `53e0c744cf5a00c0f07f68698c90305afaff8116756a141b7acb238fb853013d`（相对路径排序，逐行 `sha256  path` 加换行）。Gateway 应用版本为独立的 `1.1.2-SNAPSHOT`，不作为 Plugin 或 Skill 版本。

旧域协议入口已返回 410。更换连接地址不保留旧 Issuer/resource 的 OAuth 身份；用户安装新版本后需按宿主流程重新授权，固定旧 tag 不会自动更新。本次不修改用户安装、OAuth 缓存或认证服务，也不创建求解任务。

验证结果记录在 [验收清单](../acceptance.md)。包测试和隔离原生协议检查不能代替真实目标桌面客户端的新版本安装、完整登录、续期或 MCP Apps 图形渲染验收。本次推送仅覆盖 Plugin 主线及 `v1.3.13` 标签；Gateway 仓库、服务部署和用户安装独立处理，所有既有标签指向与历史发布说明保持原样。
