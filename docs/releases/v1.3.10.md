# Planly Plugin v1.3.10

日期：2026-10-19。版本已更新，标签 `v1.3.10` 待发布。

## 变更

- 求解参数摘要前展示求解强度与求解约束两组选项，由 Skill 传入预选值；按需切换后一次“确认求解”，不调整即可直接确认。
- 强度名称为轻量、标准、增强，未指定时采用标准档；日常不展示内部规格编码或硬件参数。
- 约束名称为全面兼顾、均衡优先、效率优先；无指定或继承设置时初选全面兼顾。模式按当前 ImageVersion 的公开方案映射，缺少对应方案时展示实际可用项，不编造权重或重命名不相符的方案。
- 保留已有规格、自定义约束、草稿与候选映射绑定、费用复核和重复提交门禁；旧 Gateway 或无 UI 宿主使用按钮或文字确认。
- 同步 16 个公开 Skill 文件；公开端点、OAuth、MCP 连接配置和品牌不变。

## 配套与验证

多组卡片由配套 Gateway 提供，Plugin 不捆绑 HTML；须先部署支持 `groups`、`selected_option_ids` 和 `confirm_label` 的 Gateway。本次不修改引擎权重，也不新增实时规格查询。

自动化结果见 [验收清单](../acceptance.md)，来源见 [同步记录](../gateway-skill-sync.md)。本地模拟宿主验证不代替真实 GPT Desktop 验收；本次未部署服务或更新用户安装。
