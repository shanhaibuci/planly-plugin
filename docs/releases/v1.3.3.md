# Planly Plugin v1.3.3

日期：2026-09-28。

## 变更

- 同步 Gateway 提交 `8a34acd8` 的公开 Skill，并将 Plugin 与内置 Skill 统一升级到 `1.3.3`。
- 使用独立的 `map_display_tool_name`、`gantt_display_tool_name` 和两份 UI 资源，不再通过单工具的 `view` 参数切换地图 / Gantt。
- 地图下方 Gantt 入口只发送意图，下一轮重新核对目录后调用 Gantt 工具；任务或连接改变时不复用旧映射，不自行拼接工具名。
- 结果解释只使用模型可见摘要和对应 Schema；基础详情和 UI 专用 `_meta.gateway_ui.engine_view` 不作为模型已取得的分析证据。
- 保留 `gateway:mcp offline_access`，公开 Client ID、回调、端点、生成配置和品牌素材不变。

## 升级

1. 将市场 Git ref 切换到 `v1.3.3`，再更新或重新安装 Planly 插件。
2. 开启新会话，确认使用当前插件连接；仅在宿主要求时完成 OAuth，不创建第二条用户级 MCP。
3. 确认目标 Gateway 与 ImageVersion 已提供新契约；缺少展示提示、工具或资源时使用摘要和网页入口，不回退旧单工具契约。

本版新建 `v1.3.3`，不移动或覆盖既有 `v1.3.2`。固定旧 tag 的客户端不会自动升级。

## 验证与边界

常规测试共 58 项，54 项通过，4 项可选原生客户端测试按设计跳过。Skill / Plugin 结构校验、MCP 配置生成一致性、上游 Skill 比对（仅版本声明不同）及 `git diff --check` 通过。

本次仅发布插件包规则，不部署 Gateway 或引擎，不修改用户配置或认证策略。双工具 / 双资源契约冻结不表示上游迁移完成；真实 OAuth 续期、地图联网、inline/fullscreen、刷新和回放仍须独立验收。
