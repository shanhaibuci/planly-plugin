# Planly Plugin v1.3.0

本版交付插件独立 MCP 接入、只读 MCP Apps 使用指导及新版 Planly Logo；不代表真实客户端可视化已经联合验收。

## 主要变化

- 删除历史远端 App 引用，插件通过 `.mcp.json` 自带 `planly` HTTP MCP，由宿主管理 OAuth；Gateway 地址与公开 OAuth 注册信息保持不变。
- Skill 区分插件与独立安装，优先使用可信插件连接，不重复创建用户级 MCP，不硬编码宿主工具前缀。
- 支持发现 Gateway 公共卡片与版本化结果展示工具，按实际 `display_tool_name` 请求地图、Gantt、单工程师路线和规划回放。页面及安全数据仍由 Gateway 提供，插件不捆绑结果 HTML。
- 无 UI、版本未就绪或权限变化时安全降级；创建求解任务仍须用户明确确认。
- 更新 Planly 线条骑士 A 版的小图标、浅色/深色 Logo，以及 Outfit Bold 700 字标许可。
- 增加配置生成、品牌指纹、接入边界与真实 Codex 隔离协议测试。

## 升级

1. 将插件市场的 Git ref 切换到 `v1.3.0`，再更新或重新安装 **Planly 场景求解**。固定旧 tag 的市场不会因刷新自动切换版本。
2. 启用插件自带的 `planly` MCP，在宿主 Authenticate 入口完成 OAuth；旧远端 App 授权不会自动迁移。
3. 开启新会话，使用 `$planly-solver` 查看已有成功任务并请求地图/Gantt。
4. 如已有独立 Gateway 连接，核对当前插件来源与账号，避免混用；本版不自动删除用户原配置。

## 验证与限制

- 包、配置、Skill 与品牌合约测试 51 项通过；真实 Codex 0.155.0 隔离安装/OAuth 请求/UI 资源传输测试 2 项通过。测试不使用真实账号、不创建求解任务。
- Plugin/Skill 结构校验通过，新 Logo 与已确认品牌源逐字节一致。
- 真实目标客户端 OAuth 完整流程、MCP Apps 会话渲染/全屏、地图联网与回放仍未验证，详见 [验收清单](../acceptance.md)。
- 直接 MCP 插件面向兼容的桌面端/Codex；不声称同一 GitHub 包可直接用于 ChatGPT 网页端。
- 此发布不修改 Gateway 服务端、引擎、远端 App 或 OAuth 登录页的品牌配置，也不进行服务部署。
