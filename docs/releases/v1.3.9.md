# Planly Plugin v1.3.9

日期：2026-10-19。发布标签：`v1.3.9`，不移动既有 tag；不部署 Gateway 或更新用户安装。

## 变更

- 用本次硬约束、目标优先级及实际指标说明派单取舍，让业务结论兼顾可理解性与专业性；得分按解释价值展示，不推造分项贡献或时间单位。
- 通过删除和替换收敛重复限制，`SKILL.md` 与结果解释参考合计比 v1.3.8 减少 1,450 个字符，不靠叠加例外放宽表达。
- 保留任务与来源绑定、证据强度、时间语义、真实异常披露和收费创建确认；不自动调参或创建对照求解。
- 16 个公开 Skill 文件与 Gateway 同步；不包含客户数据、问答原文或凭据，不改公开端点、OAuth、MCP 配置及品牌。

## 验证与限制

版本和包契约检查见 [验收清单](../acceptance.md)，来源和文件树指纹见 [同步记录](../gateway-skill-sync.md)。

发布内容除版本号外与本轮最终行为验证快照一致：两次同址问答独立回放及一次得分/最优性追问通过，独立盲评认为两份新回答比旧版更能解释真实目标取舍。前两轮表达未通过的记录保留，没有将修订前失败算作通过；表格仍可更明确全天合计包含其他新单。

这些验证使用已保存的历史公开 Gateway 响应，不是实时查询，未创建收费任务。此前人选归因问题未全面重测，不能宣称所有问答已稳定或达到录屏标准；真实 OAuth、GPT Desktop 与图形 UI 仍待独立验收。
